## Techniques & Workflows

- **Multi-agent parallelism** is now practical day-to-day. Cursor 3's Agents Window and Claude Code worktrees both enable running independent agents on separate tasks simultaneously — good for reviews, tests, and feature branches in parallel.
- **gh skill** (GitHub CLI v2.90.0+, Apr 16) — new command to discover, install, and publish agent skills that work cross-platform across Copilot, Claude Code, Cursor, Codex, and Gemini CLI. Worth adding to your dotfiles workflow.
- **Self-hosted open-source stack** — teams report 30–60% lower monthly costs vs. GitHub Copilot Enterprise by switching to Tabby (autocomplete) + Continue (chat/edit) + Aider (CLI commits).
